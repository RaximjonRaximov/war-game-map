# war-game-map

Browser-based world domination war game with a real-world style map.

## Play

Open `index.html` in a browser, or deploy the repo as a static site.

## How to play

1. Click any country on the map to play as it (for example Russia).
2. Your country is **blue**, the enemy is **red**, neutral countries are **gray**.
3. Each turn you get reinforcements based on how many countries you own.
4. Select one of your countries and click a connected enemy/neutral country to attack.
5. Battles use Risk-style dice rolls.
6. Conquer all countries to win.
