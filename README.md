# war-game-map

Browser-based war strategy game with an interactive map.

## Play

Open `index.html` in a browser (or deploy the repo as a static site).

## How to play

- Blue team is yours, red team is the enemy.
- Select one of your blue units to see where it can move.
- Click a highlighted tile to move, or click an adjacent enemy to attack.
- Destroy the enemy base or all enemy units to win.
- Press **End Turn** when you are done moving.
